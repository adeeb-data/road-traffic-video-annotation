# Annotation Details

## Project Name
Road Traffic Video Annotation

## Annotation Tool
CVAT (Computer Vision Annotation Tool)

## Dataset Information
- Video Duration: 5 seconds
- Total Frames: 52

## Annotation Process
1. Uploaded the road traffic video into CVAT.
2. Created labels for the required object categories.
3. Annotated the objects across video frames.
4. Reviewed the annotations for consistency.
5. Exported the completed annotations.

## Annotation Categories
- Car
- Bus
- Truck
- Person
- Traffic Light

## Quality Checking
- Checked object boundaries.
- Verified class labels.
- Reviewed annotations across frames.
- Checked tracking consistency, if tracking was used.

## Export Formats
- CVAT for video 1.1
- MOT 1.1 (if applicable)

## Project Objective
To gain practical experience in video annotation, object detection and object tracking.
