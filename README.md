# Road Traffic Video Annotation Using CVAT

## Project Overview
This project focuses on video annotation and object tracking using CVAT (Computer Vision Annotation Tool).

A 5-second road traffic video containing approximately 150 frames was manually annotated.

## Tools Used
- CVAT – Video Annotation
- MOT 1.1 – Multi-Object Tracking Dataset
- CVAT for Video 1.1 – Annotation Export
- GitHub – Project Documentation

## Annotation Activities
- Video frame annotation
- Object detection
- Bounding box labelling
- Object tracking across video frames
- Object classification using separate labels

## Dataset Information
- Video Duration: Approximately 5 seconds
- Total Frames: 52
- Annotation Tool: CVAT
- Project Type: Video Annotation and Object Tracking

## Objective
To gain practical experience in video annotation, object tracking, and preparing structured datasets for computer vision applications.
